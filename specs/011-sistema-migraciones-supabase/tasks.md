# Tareas — Sistema de migraciones de Supabase

## Gate obligatorio para remoto

Ninguna tarea autoriza conexión o modificación del remoto. `supabase link`, repair remoto, push remoto y operaciones equivalentes quedan fuera de alcance y requieren autorización independiente futura, explícita y previa. La prohibición de ejecutar SQL o comandos CLI aplica a esta fase de planificación; tras su aprobación, la implementación local prevista por RF-8 puede iniciar Supabase local aislado y aplicar la baseline exclusivamente a una base local nueva y desechable para validar RF-3. No configurar credenciales para conectar el remoto ni ejecutar contra una base local existente/no desechable.
